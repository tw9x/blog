一个用来管理读书笔记的小系统。核心想法是：笔记必须先是纯文本，工具随时可以换掉。

## 起因

之前笔记散在三四个地方——手机备忘录、纸质本子、几个不同的 App。结果是写的时候方便，找的时候找不到，更没有回头重看的习惯。

我想要的其实很简单：

- 读书时的摘抄和感想能快速记下来
- 读完之后能整理成一篇完整的东西
- 半年后想找某本书的观点，能搜到

## 怎么做的

每本书一个 Markdown 文件，用固定格式：

```markdown
# 书名
作者 / 读完日期 / 评分

## 摘抄
> 原文……
（自己的话复述一遍）

## 感想
（读完整理）
```

配一个 Python 脚本，扫描这些文件，生成：

- 按年份和评分排序的书单
- 按标签分类的主题索引
- 一个全文搜索的静态页面

## 遇到的坑

**摘抄太顺手的代价**。一开始我抄得很多，后来发现抄下来的内容基本不会再翻。反倒是用自己的话复述过的，才真的变成自己的理解。后来改成：想抄的地方必须先写一句「为什么抄」。

**标签体系会失控**。标签加着加着就到了三十多个，同义词一大堆。后来砍到八个固定标签，克制住了。

## 为什么归档

这套流程后来被我合并进了博客项目——读书笔记直接作为文章发布，不再单独维护一个系统。

不过原来的格式留下了，那几条原则现在还在用：纯文本、先复述再摘抄、标签要少。
